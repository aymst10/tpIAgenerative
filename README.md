# TP IA Generative

Ce dépôt est organisé par parties afin de faciliter le rendu du travail.

- `partie_1_bases_pytorch/` : bases de PyTorch, réseau de neurones et régression.
- `partie_2_autoencodeur_mnist/` : autoencodeur appliqué à MNIST.
- `partie_3_architecture_transformer/` : RNN, LSTM, Transformer, GPT et BERT.
- `partie_4_prompt_engineering_sentiment/` : analyse de sentiment avec prompt engineering.
- `partie_5_prompt_engineering_bases/` : bases du prompt engineering.
- `partie_6_rag_pdf_chatbot/` : chatbot RAG avec notebook et application Streamlit.
